# PDFOCR 공통 패키지 목록
#
# 여기에는 어느 PC에서나 똑같이 쓰는 것만 적는다.
#
# 글자를 읽는 실행 부품(onnxruntime)은 이 파일에 없다.
# 그래픽카드 종류에 따라 설치해야 할 것이 달라지는데, 셋은 이름이 같아
# 한 PC에 하나만 깔 수 있기 때문이다.
#
#   NVIDIA 그래픽카드  -> onnxruntime-gpu      (CUDA 가속)
#   AMD / Intel 그래픽 -> onnxruntime-directml (DirectML 가속)
#   그래픽 가속 불가    -> onnxruntime          (CPU 처리)
#
# 아래 명령을 쓰면 이 PC를 살펴보고 알맞은 것을 알아서 깔아 준다.
#
#   python scripts\setup.py
#
# 이 파일만 설치하면 OCR이 동작하지 않는다. 반드시 위 명령을 함께 실행할 것.
